# Yom · Landing de pago

Página estática con branding Yom (paleta del Template Presentación Yom v2025) que redirige al checkout de dLocal Go.

## Configurar el link

Editá `config.js`:

```js
window.YOM_PAYMENT = {
  url: "https://checkout.dlocalgo.com/validate/..."
};
```
